# RSI 知识与方法论库（rsi-knowledge）

一份**随时可查、可引用**的 RSI（Recursive Self-Improvement，递归式自我改进）知识底座。
它不执行任何动作，只负责把概念、度量、分级框架和实测数据沉淀清楚，供你在写方案、读文章、聊天时快速引用。

来源：Theseus Labs《The Last AI Built by Humans》RSI 行业分析报告（2026-09），arXiv:2609.11873，项目主页 https://theseus-labs-rsi.github.io/
分析基础：72 家公司/团队公开材料、393 组模型-基准观测、10 大能力领域（2023–2026）。

---

## 它是什么

RSI = 不让人类一遍遍手把手教 AI，而是让 AI 自己闭环
**试错 → 验证 → 沉淀经验 → 改进自己**，并且每一轮改进让下一轮更高效可靠。

类比：**错题本**——AI 自己做题、自己核对答案、把错因写进本子，下次直接翻本子，越做越准；
到了最高级（L5）它还会改进"记错题的方法"本身。

本 skill 把这套思想工程化、可度量化，给出一套判断 AI 能力边界、选择发力方向的标尺。

---

## 何时使用

- 解释或向他人说明「RSI / 递归式自我改进」的定义与来龙去脉
- 引用 **HCI 能力余量闭合指数**、**L1–L5 自主权框架**、**四大评估追问**
- 引用大厂（OpenAI / Anthropic / 腾讯 / Meta 等）的 RSI 实践阶段与定位
- 引用产业实测数据（缺陷率、加速比、评分提升等）支撑论点

## 包含内容（速查）

| 模块 | 一句话 |
|---|---|
| 概念定义 | 分析单元是「改进循环」：人类与 AI 在循环里各担多少责任，决定自主权级别 |
| HCI 指标 | `(当前−基准)/(100−基准)×100`，衡量某项能力离满分还差多少已被填补 |
| L1–L5 框架 | 人类逐步退出、AI 逐步接管「改进循环」的五个段位 |
| 大厂进度 | 绝大多数仍停在 L1–L2；腾讯 R-Zero 到 L3；Factory/OpenAI 税务智能体候选 L4 |
| 产业实测 | Humanlaya 缺陷率 9%→3.7%；面壁 ForgeStencil 1.15–1.9×；小红书推荐 +7% |
| 四大追问 | 可衡量 / 可保持 / 可迁移 / 可回滚——区分真改进与刷榜 |
| 四步闭环 | 重构环境 → 暴露缺口 → 再训练模型 → 迭代环境（Theseus Labs 落地解法） |

### 2026 年各领域 HCI（前沿水平，越高越接近天花板）
| 领域 | HCI |
|---|---|
| 前沿数学 | 86.4 |
| 研究生级科学 | 85.8 |
| 广博知识 | 77.2 |
| 法律推理 | 64.5 |
| 多模态推理 | 62.2 |
| 前沿学术广度 | 60.4 |
| 搜索与终端 Agent | 56.8 |
| 软件工程 | 52.6 |
| 工具调用 Agent | 39.9 |
| 网络安全 Agent | 91.9 |

**结论**：标准化考试类能力快到顶，真实任务执行（软件工程 52.6 / 工具调用 Agent 39.9）缺口最大 = RSI 红利最高。

### L1–L5 自主权
| 级别 | 名称 | 人类负责 | AI 闭环接管 |
|---|---|---|---|
| L1 | 执行自主 | 设计任务、环境、更新策略 | 执行任务、更新 |
| L2 | 策略自主 | 设计任务、环境 | 设计更新策略（策略持久化） |
| L3 | 经验获取自主 | 设计环境 | 规划经验获取、执行、设计更新策略 |
| L4 | 环境适应自主 | 设定边界 | 与环境交互、设计更新策略 |
| L5 | 递归继承自主 | 设定边界 | 改进「改进系统本身」 |

> L1–L4 在既定机制下提能力；**L5 的「决定后续改进的机制」本身由 AI 接管，才可能触及有效递归**——但其持续递归收益目前仍缺乏充分验证。

## 与其他 skill 的关系

- **下游**：`rsi-self-improvement-designer` 在设计具体项目自改进方案时，会把本 skill 当作「认知/定级」层来引用（给目标定级 L 几、找 HCI 缺口最大的方向）。
- **落地层**：`wikiskill` 是本 skill 所描述的「经验沉淀」原则的跨平台工程实现（`.wiki/` 三层架构 + 验证-回滚）。

三者构成一条引用链（认知 → 设计 → 实现），详见集合根目录 `README.md`。

---

## 注意事项

- 只靠自评分宣称「我进步了」无效，必须在独立评估下确认。
- 不要承诺 L5 级递归收益（缺乏充分验证），现实目标通常是 L2–L3。
- 本 skill 是纯知识库，不含任何可执行脚本，可跨平台、跨 agent 使用，不依赖任何工具私有目录。
