# RSI 知识与方法论库

本 skill 沉淀 RSI（递归式自我改进）领域的核心概念、度量指标、分级框架与产业实测数据，作为可查询的知识底座。详细内容见 `references/rsi-reference.md`。

## 何时使用
- 解释"RSI / 递归自我改进"的定义与来龙去脉
- 引用 HCI 能力余量闭合指数、L1–L5 自主权框架、四大评估追问
- 引用大厂（OpenAI / Anthropic / 腾讯 / Meta 等）的 RSI 实践阶段与定位
- 引用产业实测数据（缺陷率、加速比、评分提升等）支撑论点

需要具体定义、公式、分级描述或数据时，读取 `references/rsi-reference.md`。该文件按"概念 → 度量 → 框架 → 产业实践 → 四大追问 → 四步闭环"组织，便于检索。
