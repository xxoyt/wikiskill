## 1. 概念定义

**RSI（Recursive Self-Improvement，递归式自我改进）**：让 AI 不再依赖人类手动调参来提升能力，而是自主闭环"试错 → 验证 → 沉淀经验 → 改进自己"，且每一轮改进让下一轮改进更高效可靠。

分析单元是"**改进循环**"（improvement loop）：人类与 AI 在循环中各承担多少责任，决定了自主权级别。

---

## 2. 度量指标：HCI（Headroom-Closed Index，能力余量闭合指数）

衡量：相较于某项评测最初的前沿水平，模型填补了多少通往满分的差距。

```
HCI = 100 × (共识得分 − 基准前沿) ÷ (100 − 基准前沿)
```

其中 **基准前沿** = 该基准进入数据集第一年的第 90 百分位模型分数；**共识得分**按数据源加权，以抑制自报结果偏差。

示例：基准年 60 分、当前 80 分 → HCI = 50，即原有提升空间已被填补一半。

汇总某领域时：先取各评测每年 HCI 的第 90 百分位代表当年前沿水平，再按参与模型数量的平方根加权平均（兼顾覆盖度，避免最大评测主导）。

### 2026 年各领域 HCI（前沿水平）
| 领域 | HCI |
|---|---|
| 网络安全 Agent | 91.9 |
| 前沿数学 | 86.4 |
| 研究生级科学 | 85.8 |
| 广博知识 | 77.2 |
| 法律推理 | 64.5 |
| 多模态推理 | 62.2 |
| 前沿学术广度 | 60.4 |
| 搜索与终端 Agent | 56.8 |
| 软件工程 | 52.6 |
| 工具调用 Agent | 39.9 |

**结论**：模型在"标准化考试"上快摸到顶（数学/科学 >85），但在"真实任务执行"上刚起步（软件工程 52.6、工具调用 Agent 仅 39.9）。同为 Agent，**网络安全 Agent 已达 91.9**，与工具调用 Agent 相差 52.0 点——Agent 内部能力分化极大，不能一概而论。

**RSI 延伸公式（本仓库自拟外推，非论文公式）**：`R = 100 − 0.22 × (100 − 2026年HCI)`，假设 RSI 按 0.22 系数填补缺口：
- 网络安全 91.9 → 98.2
- 软件工程 52.6 → 89.6
- 搜索与终端 56.8 → 90.5
- 工具 Agent 39.9 → 86.8

**含义**：现有能力缺口越大的领域，从 RSI 获得的潜在提升红利越高。

## 3. 五级自主权框架（L1–L5）

按 AI 在改进循环中承担的责任分级，人类投入逐步退出、AI 接管逐步扩张：

| 级别 | 名称 | 人类负责 | AI 闭环接管 |
|---|---|---|---|
| L1 | 执行自主 | 设计任务、设计试验环境、设计更新策略 | 执行任务、更新 |
| L2 | 策略自主 | 设计任务、设计试验环境 | 设计更新策略（策略持久化沉淀） |
| L3 | 经验获取自主 | 设计试验环境 | 自主规划经验获取、执行、设计更新策略（经验设计持久化） |
| L4 | 环境适应自主 | 设定边界 | 自主规划经验获取、与环境交互、设计更新策略（环境适应持久化） |
| L5 | 递归继承自主 | 设定边界 | 改进"改进系统本身"（系统设计本身持久化沉淀） |

**类比**：能力提升如登山。L4 是在既定路线上适应环境完成目标；L5 关注"登山方法"本身——自主发现能力前沿、思考受阻原因、选择更优路线，并把验证过的新方法传给下一代继续改进。

**关键区分**：L1–L4 在既定改进机制下提升任务能力；**L5 的"决定后续改进的机制"本身由 AI 接管，才可能触及有效递归**。L5 的持续递归收益目前仍缺乏充分验证。

**安全边界**：总体目标与安全边界始终由人类把关；真正的提升必须在同等预算下经独立评估确认，不能仅靠自我修改或自评分宣称进步。

## 6. 四大评估追问（L5 评估必问）

真正的递归改进不能只看一次成功，要追问：
- **可衡量**：改进是否真实？能否在独立评估下复现？
- **可保持**：改进能否持久保留而不退化？
- **可迁移**：改进能否跨任务、跨领域复用？
- **可回滚**：改进失效时，能否安全撤回？

四问决定 RSI 是"一次性刷榜"还是可持续改进能力。

---

## 7. Theseus Labs 落地解法：环境—数据—模型协同进化

四步闭环：
1. **重构环境**：把原始工作区还原成可供 Agent 训练与评估的环境
2. **暴露缺口**：借新环境发现真实能力缺口，并生成训练数据
3. **再训练模型**：用生成的数据训练任务模型
4. **迭代环境**：用更强模型推动下一轮环境迭代，形成闭环

---

## 8. 四领域进展速度差异

软件工程进展最远；科学、机器人技术、医疗保健更受限（反馈更难获得或更冒险地验证）。

决定 RSI 在每个领域进展速度的三因素：**反馈成本、可验证性、部署约束**。

→ 这解释了为何软件工程与工具型 Agent 是各家发力第一站：反馈廉价、验证明确、部署链路短，天然是 RSI 循环最容易闭合的土壤。
