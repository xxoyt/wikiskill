## 2. 失败模式模板（patterns.md 中追加）

```markdown
### FM-007: Excel 下拉列表超 255 字符
- **触发条件**：使用 POI/FastExcel 创建数据验证下拉列表，选项内容超过 255 字符
- **表现**：运行时抛出 IllegalArgumentException，导出中断
- **根因**：Excel BIFF 格式限制单个验证公式不超过 255 字符
- **解决方案**：将选项数据写入隐藏 sheet 的命名区域，用 INDIRECT 引用
- **发现日期**：2026-08-28 | **出现次数**：3
```

## 4. 技能文件模板（skills/xxx.md）

```markdown

version: 1.0
created: 2026-08-31
updated: 2026-08-31
status: active
source_patterns: [FM-003, FM-005]
---

# 数据推送字段映射校验

## 适用场景
与省平台进行 SOAP/JSON 数据推送前，校验字段映射的完整性和命名一致性。

## 执行步骤
1. 读取省平台 WSDL 或接口文档中的字段定义
2. 对比本地代码中的实体类字段名
3. 生成差异报告（缺失/命名不一致/类型不匹配）
4. 对不一致项逐一修复并编译验证

## 注意事项
- 省平台文档版本可能更新，始终以最新 PDF/WSDL 为准
- 注意大小写差异（camelCase vs snake_case）
- 嵌套对象的字段需逐层对比

## 变更历史
- v1.0 (2026-08-31)：初始版本，基于 FM-003 和 FM-005 提炼
```
